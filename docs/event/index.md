# Управление мероприятием

Управление мероприятием доступно его `Создателю` и `Менеджерам`, которых создатель назначает. Чтобы перейти к управлению мероприятием, нажмите соответствующую кнопку на странице со списоком мероприятий

![](/img/event/admin/update/01.home.png)

или в заголовке страницы возле названия мероприятия

![](/img/event/admin/update/02.header.detail.png)

Страница управления мепроприятием в зависимости от [настроек](create.html) может выглядеть вот так

![](/img/event/admin/update/03.update.png)
